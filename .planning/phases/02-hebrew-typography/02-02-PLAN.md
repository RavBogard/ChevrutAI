From src/components/sheet/SourceBlock.jsx — existing hasContent helper (lines 26-31):
```javascript
const hasContent = (text) => {
  if (!text) return false;
  if (typeof text === 'string') return text.trim().length > 0;
  if (Array.isArray(text)) return text.length > 0 && text.some(t => t && typeof t === 'string' && t.trim().length > 0);
  return false;
};
```
Copy this exactly into SheetPreview.jsx. Keep SheetPreview self-contained.

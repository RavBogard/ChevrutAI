<objective>
Patch the Zustand store to guarantee every source block has a stable unique `id`, extract the sortable DnD wrapper into `SortableItem.jsx`, and add `DividerBlock.jsx` as the fourth block type.

Purpose: All other Phase 3 plans depend on stable source ids. The current codebase (SheetView.jsx line 112) uses `source.ref` as the DnD identity key, which silently breaks when the same Sefaria passage is added twice. This plan fixes that root cause and adds the two new files that SheetCanvas (Plan 03) will import.

Output: Patched useSheetStore.js, new SortableItem.jsx (extracted from SheetView), new DividerBlock.jsx.
</objective>

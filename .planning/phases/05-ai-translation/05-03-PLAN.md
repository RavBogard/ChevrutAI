formatText function (lines 12-17) — use for both source.en and source.aiTranslation:
```javascript
const formatText = (text) => {
    if (Array.isArray(text)) { return text.map(t => stripHtml(t)).join('\n'); }
    return stripHtml(text);
};
// stripHtml strips HTML tags and decodes entities
```

```javascript
// BEFORE:
```
